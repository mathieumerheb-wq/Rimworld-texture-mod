# RJW Animal Textures

Cosmetic texture test for RimWorld 1.6. The mod adds images for existing hediffs, four genital genes, a lynx ears gene, and a black-tipped cat ears gene. FoxPenis, WolfPenis, LynxPenis, and DeerPenis have sprites. Its C# (`Assemblies/RJWAnimalTextures.dll`, from `Source/`) only patches Sized Apparel: the Anthrosonae penis placement and the variation dev menu.

This build has not been tested in-game.

## Genital genes

Fox, wolf, lynx, deer, rabbit, bovine, and bear are selectable in the RJW Genes genitalia category. Each gene replaces the penis, vagina, and anus with Race Support parts. Breasts stay as they are. Where that species has no vagina or anus of its own, the gene uses the closest existing part, or the generic mammal part. Fox and wolf use `DogVagina` and `DogAnus`. Lynx uses `CatVagina` and `FelineAnus`. Deer uses `MammalVagina` and `CervineAnus`. Rabbit uses `RodentVagina` and `MammalAnus`. Bear uses `MammalVagina` and `MammalAnus`. Bovine uses `BovineVagina` and `MammalAnus`. Until 2026-11-02, deer, rabbit, bear, and bovine kept the human vagina or anus. The part tags match existing RJW tags: fox and wolf use Knotted, Sheathed, and Tapered; lynx uses Knotted, Barbed, Sheathed, and Tapered; deer uses Flared, Sheathed, Long, and Thin.

| Gene | Penis hediff |
| --- | --- |
| `RJWAT_fox_genitalia` | `FoxPenis` |
| `RJWAT_wolf_genitalia` | `WolfPenis` |
| `RJWAT_lynx_genitalia` | `LynxPenis` |
| `RJWAT_deer_genitalia` | `DeerPenis` |
| `RJWAT_rabbit_genitalia` | `RabbitPenis` |
| `RJWAT_bovine_genitalia` | `BovinePenis` |
| `RJWAT_bear_genitalia` | `BearPenis` |

`RJWAT_mammal_breasts` changes only the breasts, to `MammalBreasts`. It is for full anthros, beside one of the genes above, which leave the breasts alone. It has its own exclusion tag, so it does not replace the genital gene. It runs after the genital genes when a pawn is sexualized (order 31; the genital genes are 30). Its icon is the RJW Genes `Extra_Breasts` icon.

Every genital gene with a penis, from any mod, has an icon in `Textures/Genes/Icons/Status/`, so the gene window shows which sprites are done. `Patches/Genes_StatusIcons.xml` points the genes from other mods at them. These 52 replace the other mods' icons, and the blank `ROBTRG_Default`. The picture is the aroused size 5 south sprite in a fixed skin tint. A green circle is this mod's sprite, or a replacement in `sized-apparel-zero/Textures`. An amber diamond is Sized Apparel's own sprite, not replaced yet. A red circle means the penis has no sprite and Sized Apparel draws the human one, so the icon is a gray human penis with the part's name. Genes that draw the same penis have the same icon. The mark is baked into the picture. After a penis gets sprites, run `ArtInventory/Build-GeneIcons.ps1` and copy `Staging/GeneIcons/*.png` over the status icons. A new gene goes in `ArtInventory/GeneIcons.csv` first. The earlier `RJWAT_*` icons in `Textures/Genes/Icons/` are no longer used.

Sized Apparel only draws a penis when a `SizedApparelHediffDef` uses that hediff's name and `BodyPartOf` Penis. Pig, cloacal, raccoon, and the other existing parts are already registered by Sized Apparel or Race Support. Fox, wolf, lynx, and deer are registered in `Defs/SizedApparelHediffDefs/SizedApparelHediffs_Penises.xml`. Without that entry the health tab still shows the part, and the sprite is never requested.

## Fantasy Races

Fantasy Races chooses private parts on the xenotype, in `EuclideanFantasyRacesRJW.ModExtension_RJWSettings`. A listed hediff replaces the generated part when the pawn is created. Deergirl listed only `CervineAnus`, so males kept the default human penis. Foxgirl and wolfgirl listed `DogPenis`.

`Patches/FantasyRaces_Penises.xml` runs only when Fantasy Races is loaded. It adds `DeerPenis` as the deergirl male genital, and replaces foxgirl and wolfgirl `DogPenis` with `FoxPenis` and `WolfPenis`. Their vaginas and anuses stay as Fantasy Races set them, except that deergirl females get `MammalVagina` from the deer gene, since Fantasy Races lists no deergirl vagina. Futa still adds that male part on top of the vagina. The same patch adds `RJWAT_fox_genitalia`, `RJWAT_wolf_genitalia`, and `RJWAT_deer_genitalia` to those xenotypes, so RJW Genes applies the penis after sexualization and when the xenotype is added to a pawn that already has parts. It also adds the Fantasy Races RJW settings to the Biotech yttakin xenotype, with `WolfPenis`. Dragongirl already lists `DragonPenis`, so her sprite changes only when the Sized Apparel files are replaced. Elf already lists `ElfPenis`. There is no lynx xenotype. Catgirl stays on `CatPenis`. Succubus and oni stay on `DemonPenis`, slimegirl on `SlimeTentacles`, orc on `OrcPenis`, harpy and arachne on their own parts.

`Defs/RaceGroupDefs/RaceGroups_FantasyAndYttakin.xml` is the RJW race-support list. It matches the fantasy-race pawn kinds `EFR_Foxgirl`, `EFR_Wolfgirl`, `EFR_Deergirl`, `EFR_Dragongirl`, and `EFR_Elf`, plus the Biotech yttakin kinds from `Pirate_Yttakin` through `Mercenary_Elite_Yttakin`. `Patches/Yttakin_Penis.xml` adds `RJWAT_wolf_genitalia` to the yttakin xenotype when Biotech is loaded, so a colonist with that xenotype gets `WolfPenis` even when their pawn kind is not one of those faction kinds.

The xenotype replacement runs inside `SexPartAdder.add_genitals`. A pawn already in a save keeps the part and the genes it was generated with. Regenerating the pawn, or adding the genital gene, is what picks up the new part.

## Anthrosonae

`Patches/Anthrosonae_Penises.xml` runs when Anthrosonae is loaded, after RJW Anthrosonae Support. That support patch was giving anthrofox and anthrowolf the canine gene, so the penis was `DogPenis`. Anthrodeer, anthrocow, and anthrobear were given the narrow gene, so the penis was `NeedlePenis`. Anthrorabbit was given the rodent gene.

Anthrosonae bodies are legless torsos drawn on the human skeleton, so a side-view penis sits on the front of the belly and the front view sits high, a little to the right of the groin. `Assemblies/RJWAnimalTextures.dll` moves the penis and balls back and down on side views, and left and down on the front view, on those bodies only, for the female, male, thin, hulk, and fat body types. Human pawns are unchanged. Copy the whole mod folder, including `Assemblies`, into the RimWorld Mods folder.

The patch replaces those genes. Anthrofox gets `RJWAT_fox_genitalia` (`FoxPenis`, `DogVagina`, `DogAnus`). Anthrowolf gets `RJWAT_wolf_genitalia` (`WolfPenis`, `DogVagina`, `DogAnus`). Anthrodeer gets `RJWAT_deer_genitalia` (`DeerPenis`, `MammalVagina`, `CervineAnus`). Anthrorabbit gets `RJWAT_rabbit_genitalia` (`RabbitPenis`, `RodentVagina`, `MammalAnus`). Anthrocow gets `RJWAT_bovine_genitalia` (`BovinePenis`, `BovineVagina`, `MammalAnus`). Anthrobear and anthropanda get `RJWAT_bear_genitalia` (`BearPenis`, `MammalVagina`, `MammalAnus`). Anthrohyena gets `RJWAT_hyena_genitalia` (`FoxPenis`, `HyenaVagina`, `DogAnus`): there is no hyena sprite, and Extra Xenotype Patches gave it Sized Apparel's `DogPenis`, which is tiny next to this mod's sprites, so it uses the fox sprite (chosen 2026-11-12). Those eight also get `RJWAT_mammal_breasts`. `Defs/RaceGroupDefs/RaceGroups_Anthrosonae.xml` sets the same parts, breasts included, on the seven Anthrosonae colonist pawn kinds it lists.

RJW Extra Xenotype Patches (`ROBTRG.RJWAditionalXenoPatchs`) adds a second genital gene, `ROBTRG_Anthro_*`, to every anthro. With both genes the xenotype had two genital genes, and only one of them applies. For those eight, the patch removes the `ROBTRG_Anthro_*` gene. Anthrocow loses that gene's `UdderBreasts` and gets `MammalBreasts`. For the others, the patch keeps the `ROBTRG_Anthro_*` gene, which already has the species vagina, anus, and breasts, and removes the RJW Anthrosonae Support gene beside it. Without RJW Extra Xenotype Patches, the support gene stays, and the furred ones (cat, griff, horse, goat, wah) get `RJWAT_mammal_breasts`.

With RJW Extra Xenotype Patches loaded, anthrocat keeps `CatPenis`, anthrodrake `DragonPenis`, and anthrohorse `HorsePenis`. Anthrogriff gets the cloacal parts, anthrogoat `BovinePenis`, anthrowah `RaccoonPenis`, and anthroshark `MarinePenis`. Without it, they stay on the support genes: feline, dragon, equine, narrow, and crocodilian. So every Anthrosonae species with a matching sprite draws it: cat (Sized Apparel cat set), fox, wolf, deer, rabbit, cow and goat (bovine), horse, drake, wah (raccoon), griff (cloacal), hyena (fox). Bear, panda, and shark have no sprite. Other anthro packs that Extra Xenotype Patches covers (Anthrosonae: Felines, Oca's Anthrosonae, Anthros for Everyone, Warriors Cats) are not installed and are not patched here. Bear has the Race Support hediff and no sprite in this mod, so anthropanda now draws the default penis instead of the narrow sprite.

## Lynx ears

Lynx ears are the gene `RJWAT_lynx_ears`. It uses the Biotech ear slot, so it replaces human, cat, pig, floppy, or pointed ears. The pictures are a head attachment at `Textures/Things/Pawn/Humanlike/HeadAttachments/LynxEars/`. South is the supplied front pair. East is the right ear from that pair, and west is mirrored from east. North is the same pair with the inner ear filled in, so the pink cavity is not visible from behind. The side ear is turned upright so it sits on the crown when the pawn faces east or west. The fur is a gray mask, and the gene uses the pawn's hair color. The black tufts stay dark. Since 2026-11-13 the ears are placed one by one on the Sized Apparel Heads cat-ear spots by `ArtInventory/Build-EarFix.ps1`: each ear is 1.3 times its earlier size, the outer edges sit at x 161 and 351 on the 512 canvas (flush with the average head's sides, so narrow heads, which draw head attachments at 87% width, pull them in with the head), the bottom at y 227, and the side ear is centered at x 246 with its bottom at 229. Before, the pair was 58 px per ear with a 5 px gap, and the side ear sat 31 px too far back. The earlier files are in `ArtInventory/Archive/2026-11-13-EarFix/`.

Black-tipped cat ears are the gene `RJWAT_blacktip_cat_ears`. The label is black-tipped cat ears. It uses the same Biotech ear slot as `Ears_Cat`, so it replaces human, cat, pig, floppy, pointed, or lynx ears. South is the front pair, with the pink inner ear. North is the back of that pair. East is the side ear, and west is mirrored from east. Since 2026-11-13 (`ArtInventory/Build-EarFix.ps1`) the fur is a gray mask in the pawn's hair color, and the black tips stay dark. The pink inner ear is a second untinted layer, `BlacktipCatEarsInner`, drawn at layer 70.5 just above the fur; its north file is blank. The two front ears are placed apart on the Sized Apparel Heads cat-ear spots, at 0.9 of their earlier size (outer edges x 161 and 351, bottom 227). North is the front pair with the inner ear filled with fur, since the earlier back picture had both ears merged into one narrow V. Before, the front ears touched in the middle and the fur was a fixed white. The earlier files are in `ArtInventory/Archive/2026-11-13-EarFix/`.

Lynx tail is the gene `RJWAT_lynx_tail`. It uses the same body attachment and offsets as the vanilla furry tail, including the cold protection and the metabolism cost. Since 2026-11-16 the pictures are drawn by `ArtInventory/Build-LynxTailV2.py` (Pillow) in the style of the other installed tails: a thick dark outline, three cel-shading bands, swept fur tufts on the underside, and a curved hook that is thin at the body and curls up into a fluffy end. The end is black, with three fur points reaching back, and a few faint streaks mark the fur. Each view fills the opaque box of the Sized Apparel furry tail on the 512 canvas: east x 83-450, y 142-406 (base on the right, toward the body); south x 20-298, y 141-409; north x 186-464, y 122-390, which is the side view mirrored. West is mirrored from east. The fur is a gray mask in the pawn's hair color; the tip, streaks, and outline stay dark. The gene icon is the side view in a lynx tan on the mod's dark icon background. Before, the tail was a thin straight painted strip, 18% of the canvas tall on east, with no outline. The earlier pictures and icon are in `ArtInventory/Archive/2026-11-16-LynxTailV2/`.

Each hediff also has a natural body-part item, a race-part entry, and an attach surgery. The fox icon is the erect front picture. The lynx ears icon is the front pair. The wolf icon is a front view from the wolf reference. The lynx icon is the barbed shaft. The deer icon is the erect front picture. Copy the mod folder into the RimWorld Mods directory to load the defs.

## Sized Apparel dragon and cat set (2026-11-25)

The replacement DragonPenis and CatPenis pictures (`DragonPenis_<size>_RNW_<dir>.png`, `CatPenis_<size>_RNW_<dir>.png`, in `Penis/`, `Horny/`, and `Balls/`, 108 files) ship in this mod instead of being pasted into Sized Apparel. When two mods provide the same texture path, Sized Apparel's lazy loader (`SizedApparelUtility.TextureExists` walks the providers from the last-loaded mod) and RimWorld's texture lookup both use the last-loaded mod's copy; this mod loads after Sized Apparel, so ours win and Sized Apparel updates no longer reset them. Keep this mod below Sized Apparel in the load order. The installed Sized Apparel folder holds its own originals again. The workspace `sized-apparel-zero/` folder is the set's history and archive. The same override approach would work for other Sized Apparel or animal textures.

## Aroused placement (2026-11-18)

Sized Apparel draws the human penis and the human balls (`Balls/Penis_<size>_<dir>`) as separate pictures: the shaft starts at the crotch and the balls hang below it. The aroused sprites that draw their own scrotum or sheath (FoxPenis, WolfPenis, LynxPenis, RabbitPenis, DeerPenis, BovinePenis, PigPenis, NeedlePenis, RaccoonPenis, and the Sized Apparel DragonPenis and CatPenis paste set) had been anchored by their bounding box on the human penis base, so the scrotum's bottom sat where the human shaft starts and the shaft root sat up to about 60 px above the crotch. `ArtInventory/Build-AnchorFix.py` moved each of them so its opaque bottom lands on the human balls' bottom (south and east) and, on east, its left edge on the balls' left edge (south stays centred): south moves down 16 to 58 px from size 0 to 5, east also moves about 10 to 35 px back. Every variant of the same hediff, size, and direction gets the same shift. A sprite already at the right edge (deer size 5 east) is not moved further right. Rest pictures and the slit or no-scrotum types (Crocodilian, Hemi, Cloacal, DemonTentacle, Elf) were not changed. This supersedes the earlier aroused anchors described in the per-hediff sections below (for example the wolf's lowered "dog anchor"). The earlier files are in `ArtInventory/Archive/2026-11-18-AnchorFix/` and `sized-apparel-zero/Archive/2026-11-18-AnchorFix/`.

## Milira

Sized Apparel looks in the pawn's race folder first and tries the hediff's own name, then the generic `Penis` (`SizedApparelsDatabase.GetSupportedBodyPartPath`). SizedApparel-Milira (`SizedApparel.Milira.Race`) ships `BodyParts/Milira_Race/Penis/Penis_*`, so a Milira always found the generic penis and never reached this mod's pictures in the Human folder. `Textures/SizedApparel/BodyParts/Milira_Race/Penis/` holds Milira copies of every penis picture in this mod (variants included) and of the dragon and cat paste set, made by `ArtInventory/Build-MiliraPenises.py`: Milira's penis sits lower and smaller, so each picture is scaled about the human anchor and moved onto the Milira anchor (aroused south 0.74, human bottom centre (256, 263) to (256, 341); aroused east 0.61, bottom-left (246, 267) to (263, 341); rest south 0.74, top centre (256, 250) to (256, 332); rest east 0.61, top-left (239, 246) to (260, 330)); north is blank, as in the Milira patch; ball files are copied (blank), so Milira's own balls are not drawn under ours. They are only used while that patch is loaded. Rebuild them with the script whenever a penis picture changes. Sized Apparel's own dog, horse, and other penises still show Milira's default.

## Penis variety per pawn

Sized Apparel has its own per-pawn variation system (verified in `sized-apparel-zero/source/SizedApparel`). `BodypartDetail_Penis.xml` lists variation names per penis hediff in the `SizedApparelBodyPartVariationDef` `PenisDetail`. When a penis hediff is created, its `SizedApparelBodyPartDetail` comp picks one name at random and saves it on the hediff; "default" means the files with no suffix. The file is then `<hediff>_<size>_<variation>_<direction>.png`, and a missing variant file falls back to the plain file of the same size. Every RJW natural penis gets the comp through `RJW_PrivatePartBase`, including this mod's hediffs. Penises made before a hediff had variations keep the default look; dev mode's "Set BodyPart Variation" changes it per pawn. Sized Apparel only links a penis to its variation list (`variationDef`) when the penis is created and does not save that link, so on a loaded save its menu showed a single "default" that did nothing. `Source/VariationMenuFix.cs` (in `Assemblies/RJWAnimalTextures.dll`, 2026-11-17) is a Harmony prefix on `SizedApparelBodyPartDetail.ShowVariationsSelect` that fills in the missing `variationDef` and `bodyPartName` the way `CompPostMake` does, so the full list appears and picking an entry works on loaded pawns. The saved variation is not touched unless the player picks an entry. `build.ps1` builds the DLL for RimWorld 1.7 with the .NET Framework C# compiler against the game's own assemblies, Harmony 1.7, and Sized Apparel 1.7 (output in `build/`, `-Install` copies it to `Assemblies/`); the earlier DLL is in `ArtInventory/Archive/2026-11-17-Assembly/`.

`Patches/SizedApparel_PenisVariations.xml` adds entries to `PenisDetail` when Sized Apparel is loaded. LynxPenis, FoxPenis, WolfPenis, RabbitPenis, and DeerPenis have three looks: `default` (the files with no suffix), `Slender`, and `Thick`. DragonPenis keeps Sized Apparel's `RNW` (the paste set) and gets `Slender` and `Thick` beside it, with their files in this mod. The variants are made by `ArtInventory/Build-PenisVariants.py` from the live sprites, for rest and aroused, south and east, sizes 0-5 (north is copied from the plain file, because once a variant's south file exists Sized Apparel uses its name for every direction and RimWorld would show the south picture from behind; balls fall back to the plain files). DragonPenis has no plain files, so on 2026-11-25 its `Slender` and `Thick` looks got blank 4x4 ball files, sizes 0-5, south, east and north, in `Human/` and `Milira_Race/` (72 files, like the blank `RNW` balls): without them Sized Apparel fell back to the skin-tinted human balls and drew a second scrotum under the dragon's own. Any new look for a hediff without plain ball files needs blank ball files too. Each sprite is narrowed to 80% (Slender) or widened to 125% (Thick) across its own long axis, found by principal-axis analysis, so the length stays on the size ladder and the organ stays on its anchor; aroused side views are then moved so their bottom row and base match the original. Added on 2026-11-17. To add variety to another hediff, run the script with its name and add an entry to the patch.

Three species also have a look drawn for their own anatomy, made by `ArtInventory/Build-PenisFeatureVariants.py` (2026-11-17) for aroused south and east, sizes 0-5; the rest pictures fall back to the plain rest, since the features are hidden when sheathed. North is copied from the plain file. `Spiny` (LynxPenis): every existing barb is redrawn bigger, raked back toward the base; edge barbs stick out of the outline; the knot lobes are skipped. `BigKnot` (FoxPenis): the original knot lobes are erased and redrawn 1.35x bigger on the same bottom, in the sprite's red with a highlight and dark outline, with the shaft redrawn on top; front views have two lobes, side views one bulb (at most 0.65 of the shaft width before scaling). `Flared` (DeerPenis): a continuous magnification of the tip, ramping from 1 to 1.5 (front) or 1.6 (side) from just below the neck, so the head is enlarged evenly and grows out of the shaft without a seam. Side views are rotated upright on a padded canvas, drawn, rotated back, and only the changed pixels are pasted, so the rest stays sharp. Deer size 5 side view already reaches the canvas edge, so its flare uses a smaller zoom. A wolf knot variant was tried and dropped: the wolf front view has no separate knot bulb.

ElfPenis (2026-11-17) has four looks: `default`, `Uncut`, `Foreskin`, and `Slender`. Uncut and Foreskin are made by `ArtInventory/Build-ElfPenis.ps1 -Variant <name> -OutRoot <staging>`, which warps Sized Apparel's human `Penis_<size>_<variant>_<dir>.png` with the same elf narrowing and lengthening (aroused north, which Sized Apparel has no variant file for, is copied from the plain elf), then `ArtInventory/Build-ElfVariantsFit.py` fits each onto the live plain elf sprite of the same size, state, and direction: scaled evenly to its opaque height (front) or box diagonal (side, since the human side views lie at a flatter angle), and placed on its anchor (rest: top; aroused: bottom; side views: left edge). Penises that started human and kept a human `Uncut` or `Foreskin` variation show the matching elf look. Slender comes from `Build-PenisVariants.py`. The Foreskin side views keep the human picture's flatter angle, and its size 2 tip has a small dark mark from Sized Apparel's own picture. The Faction - Elves xenotypes (`TOV_HighElf`, `TOV_WildElf`, `TOV_DarkElf`, `TOV_CelestiaElf`) get ElfPenis from RJW Extra Xenotype Patches' `ROBTRG_Elf_genitalia` (its `Patches/FactionElves.xml`), so this mod adds no patch for them.

## Dragon ears and tail

Dragon ears are the gene `RJWAT_dragon_ears`, in the Biotech ear slot (it replaces the pawn's other ears). Each view is one picture with both the ears and a pair of short horns: tall pointed ears with a dark inner groove, three ridges and two notches on the back edge, on the upper sides of the head, and short ridged horns on top, curving slightly back. The back view has scale ridges instead of the groove. The side view has one ear rising up and back and one horn on top. The gene draws them behind the head (layer 45; the head is at 50, hair at 62): each base starts well inside the Sized Apparel Heads average head, so the head's own outline covers it. The pictures are gray masks tinted by the hair color (changed from skin color on 2026-11-17).

Dragon tail is the gene `RJWAT_dragon_tail`, in the tail slot. It uses the vanilla furry-tail attachment and offsets, the vanilla smooth tail's cost and its +5% manipulation. It is a thick hooked tail tapering to an arrowhead spade, with dark dorsal spikes on the inside of the curve, pale belly plates with segment lines on the outside, and a few scale marks, tinted by the hair color. Each view fills a box a little larger than the Sized Apparel furry tail on the 512 canvas: east x 70-460, y 120-420; south x 14-304, y 128-420; north x 208-498, y 108-400 (the side view mirrored).

Both are drawn by `ArtInventory/Build-DragonParts.py` (Pillow), added on 2026-11-17. The webbed-fin and horn-and-ear drafts were not kept. The icons are the front ears and the side tail in a dragon red on the mod's dark icon background.

## Horse and deer ears, horse tail

Horse ears are the gene `RJWAT_horse_ears`, in the ear slot: tall, narrow upright ears high on the head, with a lighter inner groove, in the hair color. Deer ears are the gene `RJWAT_deer_ears` ("deer ears and antlers"), in the ear slot, with two layers: large oval ears sticking out sideways with a pale inner ear, in the hair color (`DeerEars`, layer 45), and antlers in a fixed antler brown, (190, 150, 110) (`DeerAntlers`, layer 44). Each antler is a beam sweeping outward with three curved tines rising from it; from the side, one antler sweeps back over the crown. All head pieces are drawn behind the head, like the dragon ears, so the head's outline and hair cover their bases. They replace AFU's deer ears for anyone who takes this gene, which drew ears and antlers as one picture in the hair color.

Horse tail is the gene `RJWAT_horse_tail`, in the tail slot, with the vanilla furry tail's attachment, offsets, cost, and cold protection. It is a narrow dock that arches up from the body and falls into a full flaring tail of hair, with wavy strands and a ragged end, in the hair color. Each view fills a box that hangs lower than the furry tail: east x 60-456, y 130-474; south x 14-300, y 140-474; north x 212-498, y 120-454 (the side view mirrored).

All three are drawn by `ArtInventory/Build-HorseDeerParts.py` (Pillow, reusing the helpers in `Build-DragonParts.py`), added on 2026-11-17. The icons are the front ears and the side tail on the mod's dark icon background.

## Install into the local Mods folder

RimWorld's local mod folder on this machine is:

`C:\Program Files (x86)\Steam\steamapps\common\RimWorld\Mods`

1. Close RimWorld.
2. Copy this project folder, `RJWAnimalTextures`, into that Mods folder. The result must be `Mods\RJWAnimalTextures\About\About.xml`.
3. Do not copy the parent `mods` workspace folder, and do not change any other mod's files.
4. If a previous copy is already there, replace only `RJWAnimalTextures`.

## In-game test

1. Enable, in this order: RimJobWorld, RJW Race Support, RJW Genes, Sized Apparel for RJW (SAR version), Sized Apparel extended if you use it, then RJW Animal Textures. The About file already asks to load after those mods. Confirm the list anyway.
2. RJW Genes requires Biotech. Sized Apparel nude part rendering needs to be on.
3. Use a disposable colony. On a nude human pawn, add the gene `rjw_genes_Pig_genitalia`.
4. Check that the genitals hediff is `PigPenis`. The renderer reads the hediff, not the gene. Removing the gene does not remove the hediff.
5. Set that hediff's severity to 0.50 for size 2, then try other severities (0.10, 0.30, 0.70, 0.90, and 1.10) to see sizes 0 through 5.
6. Face the pawn south, then east. Compare rest with aroused (`JobDriver_Sex`, or horny/frustrated). Rest shows the bulb, with the screw still inside it. Aroused shows the whole picture, bulb and screw together. East keeps the picture's own up-right angle, and west mirrors east. North is a blank texture, so the penis is hidden from behind. The ball files are blank, so a second scrotum is not drawn.
7. Open `Player.log` afterward and look for new texture errors. This build has not been tested in-game yet.

Do not treat a clean log as proof that the sprite is correct. Look at the pawn.
