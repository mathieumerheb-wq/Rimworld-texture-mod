# RJW Animal Textures

Cosmetic texture test for RimWorld 1.6. The mod adds images for existing hediffs, four genital genes, a lynx ears gene, and a black-tipped cat ears gene. FoxPenis, WolfPenis, LynxPenis, and DeerPenis have sprites. It does not add C#.

This build has not been tested in-game.

## Genital genes

Fox, wolf, lynx, deer, rabbit, bovine, and bear are selectable in the RJW Genes genitalia category. Each gene replaces the penis, vagina, and anus. Breasts stay as they are. Where that species has no vagina or anus, the gene uses the closest existing part, or the human `Vagina` and `Anus`. Fox and wolf use `DogVagina` and `DogAnus`. Lynx uses `CatVagina` and `FelineAnus`. Deer uses the human vagina and `CervineAnus`. Rabbit and bear use the human vagina and anus. Bovine uses `BovineVagina` and the human anus. The part tags match existing RJW tags: fox and wolf use Knotted, Sheathed, and Tapered; lynx uses Knotted, Barbed, Sheathed, and Tapered; deer uses Flared, Sheathed, Long, and Thin.

| Gene | Penis hediff |
| --- | --- |
| `RJWAT_fox_genitalia` | `FoxPenis` |
| `RJWAT_wolf_genitalia` | `WolfPenis` |
| `RJWAT_lynx_genitalia` | `LynxPenis` |
| `RJWAT_deer_genitalia` | `DeerPenis` |
| `RJWAT_rabbit_genitalia` | `RabbitPenis` |
| `RJWAT_bovine_genitalia` | `BovinePenis` |
| `RJWAT_bear_genitalia` | `BearPenis` |

Sized Apparel only draws a penis when a `SizedApparelHediffDef` uses that hediff's name and `BodyPartOf` Penis. Pig, cloacal, raccoon, and the other existing parts are already registered by Sized Apparel or Race Support. Fox, wolf, lynx, and deer are registered in `Defs/SizedApparelHediffDefs/SizedApparelHediffs_Penises.xml`. Without that entry the health tab still shows the part, and the sprite is never requested.

## Fantasy Races

Fantasy Races chooses private parts on the xenotype, in `EuclideanFantasyRacesRJW.ModExtension_RJWSettings`. A listed hediff replaces the generated part when the pawn is created. Deergirl listed only `CervineAnus`, so males kept the default human penis. Foxgirl and wolfgirl listed `DogPenis`.

`Patches/FantasyRaces_Penises.xml` runs only when Fantasy Races is loaded. It adds `DeerPenis` as the deergirl male genital, and replaces foxgirl and wolfgirl `DogPenis` with `FoxPenis` and `WolfPenis`. Their vaginas and anuses stay as Fantasy Races set them. Futa still adds that male part on top of the vagina. The same patch adds `RJWAT_fox_genitalia`, `RJWAT_wolf_genitalia`, and `RJWAT_deer_genitalia` to those xenotypes, so RJW Genes applies the penis after sexualization and when the xenotype is added to a pawn that already has parts. It also adds the Fantasy Races RJW settings to the Biotech yttakin xenotype, with `WolfPenis`. Dragongirl already lists `DragonPenis`, so her sprite changes only when the Sized Apparel files are replaced. Elf already lists `ElfPenis`. There is no lynx xenotype. Catgirl stays on `CatPenis`. Succubus and oni stay on `DemonPenis`, slimegirl on `SlimeTentacles`, orc on `OrcPenis`, harpy and arachne on their own parts.

`Defs/RaceGroupDefs/RaceGroups_FantasyAndYttakin.xml` is the RJW race-support list. It matches the fantasy-race pawn kinds `EFR_Foxgirl`, `EFR_Wolfgirl`, `EFR_Deergirl`, `EFR_Dragongirl`, and `EFR_Elf`, plus the Biotech yttakin kinds from `Pirate_Yttakin` through `Mercenary_Elite_Yttakin`. `Patches/Yttakin_Penis.xml` adds `RJWAT_wolf_genitalia` to the yttakin xenotype when Biotech is loaded, so a colonist with that xenotype gets `WolfPenis` even when their pawn kind is not one of those faction kinds.

The xenotype replacement runs inside `SexPartAdder.add_genitals`. A pawn already in a save keeps the part and the genes it was generated with. Regenerating the pawn, or adding the genital gene, is what picks up the new part.

## Anthrosonae

`Patches/Anthrosonae_Penises.xml` runs when Anthrosonae is loaded, after RJW Anthrosonae Support. That support patch was giving anthrofox and anthrowolf the canine gene, so the penis was `DogPenis`. Anthrodeer, anthrocow, and anthrobear were given the narrow gene, so the penis was `NeedlePenis`. Anthrorabbit was given the rodent gene.

Anthrosonae bodies are legless torsos drawn on the human skeleton, so a side-view penis sits on the front of the belly and the front view sits high, a little to the right of the groin. `Assemblies/RJWAnimalTextures.dll` moves the penis and balls back and down on side views, and left and down on the front view, on those bodies only, for the female, male, thin, hulk, and fat body types. Human pawns are unchanged. Copy the whole mod folder, including `Assemblies`, into the RimWorld Mods folder.

The patch replaces those genes. Anthrofox gets `RJWAT_fox_genitalia` (`FoxPenis`, `DogVagina`, `DogAnus`). Anthrowolf gets `RJWAT_wolf_genitalia` (`WolfPenis`, `DogVagina`, `DogAnus`). Anthrodeer gets `RJWAT_deer_genitalia` (`DeerPenis`, human vagina, `CervineAnus`). Anthrorabbit gets `RJWAT_rabbit_genitalia` (`RabbitPenis`, human vagina, human anus). Anthrocow gets `RJWAT_bovine_genitalia` (`BovinePenis`, `BovineVagina`, human anus). Anthrobear gets `RJWAT_bear_genitalia` (`BearPenis`, human vagina, human anus). `Defs/RaceGroupDefs/RaceGroups_Anthrosonae.xml` sets the same parts on the Anthrosonae colonist pawn kinds.

Anthrocat and anthrogriff stay on the feline gene (`CatPenis`). Anthrodrake stays on `DragonPenis`. Anthrohorse stays on `HorsePenis`. Anthroshark stays on `CrocodilianPenis`. Anthrogoat, anthrohyena, anthropanda, and anthrowah stay on the narrow gene, because this set has no goat, hyena, panda, or red-panda penis. Bear has the Race Support hediff and no sprite in this mod.

## Lynx ears

Lynx ears are the gene `RJWAT_lynx_ears`. It uses the Biotech ear slot, so it replaces human, cat, pig, floppy, or pointed ears. The pictures are a head attachment at `Textures/Things/Pawn/Humanlike/HeadAttachments/LynxEars/`. South is the supplied front pair. East is the right ear from that pair, and west is mirrored from east. North is the same pair with the inner ear filled in, so the pink cavity is not visible from behind. The side ear is turned upright so it sits on the crown when the pawn faces east or west. The fur is a gray mask, and the gene uses the pawn's hair color. The black tufts stay dark.

Black-tipped cat ears are the gene `RJWAT_blacktip_cat_ears`. The label is black-tipped cat ears. It uses the same Biotech ear slot as `Ears_Cat`, so it replaces human, cat, pig, floppy, pointed, or lynx ears. South is the front pair, with the pink inner ear. North is the back of that pair. East is the side ear, and west is mirrored from east. The pictures sit on the same part of the head canvas as the feline ears. The black, white, and pink are left untinted.

Lynx tail is the gene `RJWAT_lynx_tail`. It uses the same body attachment as the furry tail, including the cold protection and the metabolism cost. South hangs on the left. East is the side view, base toward the body and the dark tip outward, and west is mirrored from east. North is the south tail mirrored onto the right. The tail sits in the same part of the 512 canvas as the feline tail. The fur is a gray mask, and the gene uses the pawn's hair color. The black tip and spots stay dark.

Each hediff also has a natural body-part item, a race-part entry, and an attach surgery. The fox icon is the erect front picture. The lynx ears icon is the front pair. The wolf icon is a front view from the wolf reference. The lynx icon is the barbed shaft. The deer icon is the erect front picture. Copy the mod folder into the RimWorld Mods directory to load the defs.

## What this test build contains

PigPenis, CloacalPenis, BovinePenis, RaccoonPenis, NeedlePenis, DemonTentaclePenis, ElfPenis, CrocodilianPenis, HemiPenis, WolfPenis, LynxPenis, DeerPenis, and FoxPenis each have 54 PNGs under `Textures/SizedApparel/BodyParts/Human/Penis/`. Sized Apparel draws that whole texture at one cell, so the opaque height is the on-pawn size. Resting sprites follow the human penis height ladder, except deer sizes 0 to 2, whose rest sheath stays pink and taller so it remains visible on a pale body. Aroused sprites other than deer use the dragon height ladder: south 46, 57, 67, 144, 167, and 199 pixels, east 59, 62, 81, 130, 144, and 180. Deer sizes 3, 4, and 5 stay on the horse sprites, which reach 252 pixels at size 5. Wolf rest sizes 3, 4, and 5 stay 20% larger than the human rest ladder.

| Folder | Files |
| --- | --- |
| `Penis/` | Resting `PigPenis_0` through `PigPenis_5`, south and east |
| `Penis/Horny/` | Aroused versions of those same sizes, south and east |
| `Penis/` and `Penis/Horny/` | North files are blank 4×4 images, the same idea as HorsePenis |
| `Penis/Balls/` | Resting balls for sizes 0 through 5, south, east, and north |

Sized Apparel size indexes follow hediff severity: 0 below 0.20, 1 from 0.20, 2 from 0.40, 3 from 0.60, 4 from 0.80, and 5 from 1.01. There is no `Balls/Horny` folder. Aroused pawns keep the resting ball texture. The previous sprite set is archived in `ArtInventory/GeneratedPigPenis/`. The live pig set is the whole gene icon. Rest is the pale bulb. Aroused is that same picture, bulb and screw together. South points up. East keeps the picture's own up-right angle. The ball files are blank.

## Install into the local Mods folder

RimWorld's local mod folder on this machine is:

`C:\Program Files (x86)\Steam\steamapps\common\RimWorld\Mods`

1. Close RimWorld.
2. Copy this project folder, `RJWAnimalTextures`, into that Mods folder. The result must be `Mods\RJWAnimalTextures\About\About.xml`.
3. Do not copy the parent `mods` workspace folder, and do not change any other mod's files.
4. If a previous copy is already there, replace only `RJWAnimalTextures`.

## In-game test

1. Enable, in this order: RimJobWorld, RJW Race Support, RJW Genes, Sized Apparel for RJW (SAR version), Sized Apparel extended if you use it, then RJW Animal Textures. The About file already asks to load after those mods. Confirm the list anyway.
2. RJW Genes requires Biotech. Sized Apparel nude part rendering needs to be on.
3. Use a disposable colony. On a nude human pawn, add the gene `rjw_genes_Pig_genitalia`.
4. Check that the genitals hediff is `PigPenis`. The renderer reads the hediff, not the gene. Removing the gene does not remove the hediff.
5. Set that hediff's severity to 0.50 for size 2, then try other severities (0.10, 0.30, 0.70, 0.90, and 1.10) to see sizes 0 through 5.
6. Face the pawn south, then east. Compare rest with aroused (`JobDriver_Sex`, or horny/frustrated). Rest shows the bulb, with the screw still inside it. Aroused shows the whole picture, bulb and screw together. East keeps the picture's own up-right angle, and west mirrors east. North is a blank texture, so the penis is hidden from behind. The ball files are blank, so a second scrotum is not drawn.
7. Open `Player.log` afterward and look for new texture errors. This build has not been tested in-game yet.

Do not treat a clean log as proof that the sprite is correct. Look at the pawn.
